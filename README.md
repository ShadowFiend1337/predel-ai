# PredelAI — AI EdTech Product Analysis 

## Описание проекта

PredelAI — EdTech AI-продукт для автоматической проверки решений ЕГЭ и персонального разбора ошибок ученика.

Этот репозиторий оформлен как портфолио-кейс по бизнес- и системному анализу: от описания проблемы и процессов до требований, пользовательских сценариев и логики AI-проверки.

## Моя роль

PM / BA / SA.

В рамках проекта я занимался:

- формализацией требований к AI-пайплайну проверки решений;
- описанием пользовательских сценариев;
- анализом ошибок AI-проверки;
- переводом продуктовых проблем в технические задачи;
- приоритизацией MVP-функций;
- описанием логики обратной связи пользователю.

## Проблема

Онлайн-школы масштабируют контент, но плохо масштабируют персональную обратную связь.

Основные проблемы:

- ручная проверка домашних заданий требует много времени;
- ученики долго ждут обратную связь;
- кураторы перегружены типовыми вопросами;
- рост числа учеников увеличивает операционные затраты;
- качество обратной связи зависит от загрузки кураторов.

## Решение

Система работает по принципу AI-first, curator as quality control:

1. Ученик отправляет решение.
2. AI выполняет первичную проверку.
3. Система формирует оценку и объяснение ошибок.
4. Простые случаи закрываются автоматически.
5. Сложные и спорные случаи передаются куратору.
