# Решение по оценкам A/B и арбитра

## Реализованный алгоритм

Сравниваются баллы после внутренней валидации, пересчёта и калибровки оценщиков.

```mermaid
flowchart TD
    Start["Результаты A/B"] --> Errors{"Есть ошибка оценщика?"}
    Errors -- "Оба" --> Both["Базовый балл 0 и признак ручной проверки"]
    Errors -- "Один" --> One["Баллы доступного оценщика и ручная проверка"]
    Errors -- "Нет" --> Equal{"Баллы равны?"}
    Equal -- "Нет" --> Run["Вызвать арбитра"]
    Equal -- "Да" --> Bypass{"№13 или полный балл?"}
    Bypass -- "Да" --> Common["Принять общий балл"]
    Bypass -- "Нет" --> Run
    Run --> Valid{"Ответ арбитра валиден?"}
    Valid -- "Да" --> Guard{"A/B совпали по баллу и критериям, арбитр понижает?"}
    Guard -- "Да" --> Preserve["Сохранить общий балл, записать ответ арбитра"]
    Guard -- "Нет" --> Accept["Принять балл арбитра"]
    Valid -- "Нет" --> Same{"A/B равны?"}
    Same -- "Да" --> Common
    Same -- "Нет" --> Distance{"Разница больше 1?"}
    Distance -- "Да" --> Review["Минимум A/B и ручная проверка"]
    Distance -- "Нет" --> Min["Минимум A/B без обязательного куратора"]
    Both --> Cal["Итоговая калибровка №13/15"]
    One --> Cal
    Common --> Cal
    Preserve --> Cal
    Accept --> Cal
    Review --> Cal
    Min --> Cal
    Cal --> OCR{"Нужна принудительная OCR-маршрутизация?"}
    OCR -- "Да" --> Force["Публичный балл 0 и ручная проверка"]
    OCR -- "Нет" --> Map["Формирование публичного ответа"]
    Force --> Map
```

Калибровка может изменить балл и необходимость ручной проверки. Влияние этой операции нельзя скрывать за названием «согласие моделей». Источник правил — BR-005 и [матрица реализации](../docs/20_implementation_status.md).

## Целевая политика

При неразрешённом конфликте итог не утверждается автоматически: сохраняется предварительная оценка и создаётся ручная проверка. При отсутствии оценки возвращается `null` и технический статус. Изменение маршрута из-за OCR не подменяет отсутствие оценки математическим нулём. Полная целевая таблица находится в [бизнес-правилах](../docs/18_business_rules_and_decision_tables.md), здесь она не дублируется.
